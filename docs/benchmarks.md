# 历史验证摘要

此页合并历史阶段性报告，保留结论与限制，不把过期目录或任务计划当作当前操作指南。原始报告、输入和大体积检查点在发布仓库外归档。

## 功能与精度

早期小分子已验证SP、OPT、TSOPT、局部IRC接口及Hessian差分核验。大分子测试包含41/62/78/100/111原子五组R/P/TS。41组采用中性三重态，其余以中性单重态计算；100组没有完成充分基态筛查。

历史15个成功SP中，同H100纯流程与联算最大能量差5.506e-9 Eh；H100/4090联算最大差3.000e-9 Eh；H100联算与原生Gaussian最大差4.844e-4 Eh。后者包含DF和数值实现差别。

## 耗时

15个成功SP合计：H100联算541.25秒，平台4090联算3656.63秒，Gaussian原生40核3005.49秒。相应速度比分别6.76×、5.55×。这些数值包含当时口径的启动分摊；若计入相关失败SP尝试，比值为6.47×、4.88×。平台4090实际为约48GiB配置，不能当作普通24GB显卡。

五个双方成功的OPT比较，排除启动：纯H1002791.61秒，H100联算3413.65秒。SCF循环数分别3433、5095；轨迹与初猜策略同时有差异，不能把差距全归因于External传输或硬件。

联算外层开销（SCF/梯度/Hessian之外）在成功SP约2.57%、五个OPT约1.97%。SCF栏也包含库内部检查点等工作，不能等同于纯GPU算术时间。
